# FutureSkill Quiz Keys

Chrome/Edge extension (Manifest V3) adding keyboard shortcuts to quizzes on learn.futureskill.co.

| Key | Action |
|---|---|
| 1–9 / Numpad 1–9 / A–E | Select that choice on the current question |
| Enter or → | "คำถามต่อไป" (next question) |
| Shift+Enter | Click the last button on the page (e.g. final submit); deliberately needs Shift |

Number badges appear at the top-right of each choice. Shortcuts use physical keys, so they work with a Thai keyboard layout.

## Install
1. Open `chrome://extensions`, turn on **Developer mode**.
2. **Load unpacked** and pick this folder.
3. Reload the quiz page.
